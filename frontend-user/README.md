# Food Delivery - Customer Web Application

React web application for customers to browse restaurants, view menus, customize food items, place orders, and track order delivery in real-time.

## Technology Stack
- React 18 / Vite
- Axios / Fetch API
- Modern CSS (Flexbox/Grid, Animations)

## Getting Started

```bash
npm install
npm run dev
```

App runs locally on `http://localhost:3000` (or specified dev port).
